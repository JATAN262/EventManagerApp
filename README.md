**# Event Manager App 🎉**



**A complete Android Event Management Application built using \*\*Kotlin\*\* and \*\*Firebase\*\* with multi-role authentication for Clients, Organizers, and Admin.**



**---**



**## 📱 Features**



**### 👤 Client Panel**



**\* User Registration \& Login**

**\* Browse Event Organizers**

**\* View Organizer Portfolio**

**\* Book Events**

**\* Live Chat with Organizers**

**\* Track Booking Status**



**### 🎯 Organizer Panel**



**\* Organizer Registration \& Login**

**\* Manage Portfolio**

**\* Receive Booking Requests**

**\* Accept / Reject Bookings**

**\* Chat with Clients**

**\* Organizer Dashboard**



**### 🛠 Admin Panel**



**\* View All Users**

**\* View All Bookings**

**\* Manage Platform Activities**



**---**
